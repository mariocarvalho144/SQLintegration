# SQLintegration
Integração de SQL com Python, Excel e PowerBI

Integração SQL e Python:
  No projeto 1 de python e SQL 1, tem a integração das duas ferramentas. Através do código em python, é possível cadastrar novos usuários e seus dados   em uma banco de dados. 
  No projeto 2 de python e SQL 2, temos a integração das duas ferramentas. Através do código em python, é possível conectar o banco de dados SQL com     python e fazer uma análise de dados.

Integração SQL e Excel:
  Neste projeto, SQL é conectado com Excel para facilitar trabalho com edições,melhores visualizações e poder de criar tabelas dinâmicas.

Integração SQL e PowerBI:
  Neste projeto, SQL fornece os dados através da conexão com o PowerBI. Através dos dados fornecidos, é possível gerar grandes insights com gráficos e   e informações somente necessárias.
